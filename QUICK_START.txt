## COLUMNS IN OUTPUT CSV:

```
pair_address          = Token address
pred_proba            = Model confidence (0-1)
position_scalar       = Risk adjustment (0-1)  ⭐ REGIME
adjusted_confidence   = pred_proba × scalar    ⭐ REGIME
regime                = HMM state (0/1/2)      ⭐ REGIME
is_emergency          = Anomaly detected?      ⭐ REGIME
selected              = Portfolio filter pass?
adjusted_position_size = Final size %
```

**⭐ = NEW with regime detection**

---

## THE REGIME FILTER:

**Crash Detected?** → position_scalar = 0.0 → Signal Blocked ✗
**Normal Market?** → position_scalar = 1.0 → Signal Passes ✓
**Mixed/Transition?** → position_scalar = 0.5 → Half Size ⚠️

```python

```

To adjust sensitivity:
```python

```
